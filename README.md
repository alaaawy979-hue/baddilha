# بدّلها 🔁

تطبيق يذكّرك بمواعيد تغيير أغراض البيت (فلاتر، بطاريات، مخدات، زيت السيارة…).
تحط تاريخ آخر تغيير، تختار **سنة / سنتين / 3 سنوات** (أو أي مدة)، ويطلع لك موعد التغيير القادم فورًا مع العدّ التنازلي بالأيام والأشهر — والأقرب دائمًا فوق.

**افتح التطبيق:** https://alaaawy979-hue.github.io/baddilha/

## المزايا
- ترتيب تلقائي حسب الأقرب، وألوان حسب الإلحاح (متأخر / اليوم / خلال أسبوع / خلال شهر)
- التاريخ الميلادي والهجري (أم القرى) لكل موعد
- زر «تم التغيير» يبدأ دورة جديدة ويحفظ سجل التغييرات (مع تراجع)
- مزامنة لحظية بين الجوال والكمبيوتر — تربط الأجهزة برمز مؤقت من 8 حروف
- تنبيهات Push حتى والتطبيق مقفل (الآيفون iOS 16.4+ بعد إضافته للشاشة الرئيسية)
- ودجت للشاشة الرئيسية وشاشة القفل في الآيفون عبر تطبيق Scriptable
- رابط تقويم (iCal) يضيف كل المواعيد لتقويم الجوال/الكمبيوتر مع تنبيهاتها
- يشتغل بدون إنترنت، وقوالب جاهزة لأشهر الأشياء، ووضع داكن/فاتح، ونسخ احتياطي

## التثبيت
- **الآيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»
- **الكمبيوتر:** افتح الرابط في Edge أو Chrome ← زر «تثبيت التطبيق» أعلى الصفحة

## البنية
| الجزء | التقنية |
|---|---|
| الواجهة | HTML/CSS/JS بدون مكتبات، PWA مستضاف على GitHub Pages |
| قاعدة البيانات | Supabase (Postgres) — الجداول مقفلة والوصول عبر دوال RPC بمفتاح مساحة سري |
| المزامنة | آخر تعديل يفوز + رقم مراجعة متسلسل + Realtime Broadcast للتحديث اللحظي |
| التنبيهات | Edge Function `notify` (تشفير Web Push بدون مكتبات) يشغّلها pg_cron كل ساعة |
| التقويم | Edge Function `feed` ترجع ملف iCal للقراءة فقط |

## التطوير
```bash
npm test                       # اختبارات حساب التواريخ
python -m http.server 5173     # تشغيل محلي
npx supabase db push           # تطبيق قاعدة البيانات
npx supabase functions deploy notify --no-verify-jwt --use-api
npx supabase functions deploy feed --no-verify-jwt --use-api
```
عند أي تحديث للواجهة: ارفع رقم `VERSION` في `sw.js` و`js/config.js`.
